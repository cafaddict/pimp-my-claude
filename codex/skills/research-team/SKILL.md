---

사용자가 준 주제를 독립적인 조사 질문으로 나눈다. 후보별 비교, 공식 문서와 코드 근거,
장점과 제약 등 서로 겹치지 않는 관점 2~4개가 적절하다.

1. 질문마다 `researcher` subagent를 실행한다. 질문, 범위, 필요한 원자료와 출처 요구사항을 전달한다.
   현재 세션의 agent 수 제한에 맞춰 나눠 실행하고 모든 결과를 기다린다.
2. 각 결과에서 공통 발견, 근거가 충돌하는 주장, 출처의 날짜와 남은 의문을 대조한다.
3. 불일치가 결론을 바꾸면 해당 연구자에게 반대 근거를 전달해 추가 확인을 맡긴다.
4. 사용자 상황에 맞는 선택과 tradeoff를 직접 출처 링크와 함께 보고한다.

custom agent가 없으면 같은 역할 지시를 일반 subagent에 전달한다. subagent 도구 자체가
없으면 관점별로 순서대로 조사하고 그 제한을 알린다. 병렬로 실행했다고 꾸미지 않는다.
조사자는 파일을 수정하거나 외부 메시지를 보내지 않는다. vault 저장은 메인 agent가
사용자에게 제안하고, 요청·승인 후 `$vault-note`로 한 번만 기록한다.
