---

사용자가 준 태스크명으로 `.codex/tasks/<task-id>/todo.md`를 만든다. 이름은
소문자·숫자·하이픈으로 정리하고 빈 이름, `/`, `..`가 경로에 들어가지 않게 한다.
기존 파일이 있으면 먼저 읽고 완료한 단계를 반복하지 않는다.

1. 목표, 범위, 체크박스 계획, 현재 상태와 메모를 `todo.md`에 적는다.
2. 이미 승인된 범위는 이어서 실행한다. 새 결정이나 승인이 필요한 변경만 사용자에게 묻는다.
3. 각 단계 뒤 체크박스와 상태를 갱신하고, 예상 밖의 문제와 검사 결과를 적는다.
4. 의미 있는 교훈은 사용자가 요청한 작업 기록으로 해당 태스크의 `lessons.md`에 남긴다.
   프로젝트 전체에 적용되는 교훈만 `.codex/tasks/lessons.md`에도 반영한다.
5. 관련 검사를 통과한 뒤 상태를 완료로 바꾸고 변경 내용과 남은 제한을 보고한다.

태스크 파일은 작업 기록이다. Codex가 매 턴 자동으로 읽는 규칙이라고 설명하지 않는다.
다른 프로젝트에서도 쓸 교훈은 `$vault-note`로 저장을 제안하고, 사용자가 요청·승인한 경우에만 기록한다.
